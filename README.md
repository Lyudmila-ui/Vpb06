# Telegram-бот для задач

Бот хранит задачи в SQLite и работает в личном чате. Каждый пользователь видит и выгружает свои задачи по Telegram ID.

## Запуск в PowerShell

Нужен Python 3.11–3.15. Получите токен бота у [@BotFather](https://t.me/BotFather) и сохраните его в файле `.env` рядом с `bot.py` в строке `BOT_TOKEN=ваш_токен`. Если файла ещё нет, создайте его.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

Если вы уже создали `.venv`, достаточно повторить установку зависимостей из `requirements.txt` и запустить бота.

База `tasks.sqlite3` создаётся рядом с `bot.py` при запуске. Время создания задач хранится в UTC.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Показать приветствие и список команд |
| `/add` | Запросить текст задачи следующим сообщением |
| `/add Купить молоко` | Сохранить задачу из команды |
| `/list` | Показать все свои задачи в порядке добавления |
| `/list_csv` | Получить файл `tasks.csv` с полями `id`, `text`, `user` и `created_at` |

CSV использует UTF-8 с BOM и запятую как разделитель.
